06 / PROBLEM LAB

TEST THE WAY
YOU THINK.

Challenge yourself with an Olympiad-style problem. Use the hint only when you need it.

PROBLEM 001INTERMEDIATE

If an integer leaves remainder 2 when divided by 5, what remainder can its square leave when divided by 5?

HINT

Write the integer as 5k + 2, then square it and examine the remainder modulo 5.

SOLUTION

(5k+2)² = 25k² + 20k + 4 = 5(5k²+4k)+4. Therefore the square leaves remainder 4 when divided by 5.
